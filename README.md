## 💡 Sobre el proyecto

Este proyecto demuestra la evolución de una aplicación web sencilla desarrollada
con **Node.js y Express** hacia un flujo automatizado basado en principios de
**Integración Continua (CI) y Despliegue Continuo (CD)**.

El objetivo es comprender y aplicar el ciclo completo:

```text
                    💻 DESARROLLO
                          │
                          ▼
                   Node.js + Express
                          │
                          ▼
                       Git
                          │
                          ▼
                       GitHub
                          │
                          ▼
                  GitHub Actions
                          │
                    ┌─────┴─────┐
                    ▼           ▼
                   CI          CD
                    │           │
                    ▼           ▼
                 Validación   Deploy
                    │           │
                    └─────┬─────┘
                          ▼
                     🚀 Aplicación
